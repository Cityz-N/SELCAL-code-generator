Simple SELCAL code generator with saving capabilities of up to 24 hours.
https://cityz-n.github.io/SELCAL-code-generator/

- Standard (16-tone) and extended (32-tone, SELCAL32) codes, with the airline's name and logo
- Generated codes are checked against every flight plan on VATSIM (online and prefiled), so no one else is using them
- SimBrief: fetch your latest flight plan and check its SELCAL the same way
- Check a code: type any code to see if it's valid and free on VATSIM
- Save codes for 24 hours in this browser (up to 10 per callsign); the Saved page shows whether each one is still free

Also built into Clearway for VATSIM (MSFS panel, phone and PC): https://github.com/Cityz-N/Clearway
